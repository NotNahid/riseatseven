# RiseAtSeven

A modern, modular front-end web project built with HTML, CSS, and JavaScript. The project focuses on creating interactive UI components, smooth scrolling effects, and a clean, maintainable structure inspired by modern agency websites.

## Overview

RiseAtSeven is designed as a front-end experimentation and learning project focused on:

- Modular UI components
- Smooth scrolling interactions
- Responsive layouts
- Clean typography systems
- Lightweight animations
- Structured and reusable code architecture

## Project Structure

```
riseatseven/
│
├── index.html        Main entry file
├── styles/           CSS stylesheets
├── scripts/          JavaScript files
├── assets/           Images and media files
└── components/       Reusable UI sections
```

## Features

- Smooth scrolling experience
- Responsive design for all screen sizes
- Modular and reusable components
- Interactive hover and scroll-based effects
- Clean and maintainable code structure

## Built With

- HTML5
- CSS3
- Vanilla JavaScript

## Getting Started

Clone the repository:

```
git clone https://github.com/NotNahid/riseatseven.git
```

Open the project:

```
index.html
```

Run it in any modern browser.
